В третьей части дипломной работы мною реализовано UI тестирование для веб-приложения Stellar Burgers.

Структура проекта:
-allure_results - сгенерированный Allure-отчёт 
-locators - файлы с локаторами
-pages - методы и шаги
-tests - тестовые сценарии 
-curl.ру - URL-адреса используемых страниц
-data.ру - тестовые данные
-requirements.txt - файл с внешними зависимостями


В свою очередь папка tests содержит в себе: conftest.py - фикстуры
    - файл test_main_page:
тестирование перехода по клику на «Конструктор»;
тестированте перехода по клику на раздел «Лента заказов»;
тестирование случая, если кликнуть на ингредиент, то появится всплывающее окно с деталями;
тестирование случая, когда всплывающее окно закрывается кликом по крестику;
тестирование добавления ингредиента и увеличение счетчика ингредиента.

  - файл test_order_feed
  тестирование открытия всплывающего окна с деталями заказа
  тест отображения созданного заказа в ленте заказов
  тест увеличения общего счетчика заказов после создания нового
  тест увеличения дневного счетчика заказов после создания нового
  тест появления номера заказа в разделе "В работе
